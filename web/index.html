why the buttons behave like this
Changing the selector while running, E-STOP, or a collision stops the robot where it is and demands Home before Autorun will run again: after a sudden stop the sequencer does not know what pose the axes ended in. Cycle stop is different — the job in hand is finished first, so no board is left in mid-air, and Autorun can be used again straight away. A board being gripped is kept held through all of that, and Autorun resumes its delivery. Home folds the arm only — the rail stays put, so home is valid anywhere along it. Speed scales axis velocity (cycle and jog), not acceleration and not the gripper; clamped to 1..100 % in the PLC.

Stations

buffer rule
Empty ICCs are filled first, both of them → a finished DW is cleared to WIP OUT → a finished ICC moves into a free DW. That order is what keeps the 17-second testers busy, and what stops four full machines from deadlocking each other. Every machine times itself, concurrently.

jog notes
The real machine jogs one step at a time (10); "hold to move" is an addition for this view. Jog is live only with the selector at MANUAL — two command sources for one arm fight every scan. Opening the gripper while holding a board DROPS it, and clears the job with it. A pose that would enter a machine body is rejected by the PLC before any axis moves. Elbow up exists only in the V2 FB; off = the same branch the machine uses.
